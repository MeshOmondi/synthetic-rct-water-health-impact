# synthetic-rct-water-health-impact
Synthetic randomized controlled trial assessing the impact of piped water connections on household health expenditure
# Project Overview

This project presents a synthetic Randomized Controlled Trial (RCT) designed to evaluate the impact of connecting rural households to piped water. The study investigates whether improved access to safe water reduces monthly health expenditure and improves household welfare.

#Research Question

Does connecting households to piped water reduce monthly health expenditure and improve water-related outcomes?

# Objectives

- Evaluate the impact of household water connections on monthly health expenditure.
- Assess changes in water collection time.
- Measure changes in distance to the nearest water source.
- Examine changes in monthly water expenditure.
- Assess changes in cholera incidence.

# Dataset

The dataset is entirely synthetic and was created for learning and demonstration purposes.

- 400 households
- Baseline survey
- Endline survey
- Panel dataset (800 observations)
# Variables
The dataset includes:
- Household ID
- Household Size
- Village
- Monthly Income
- Treatment Status
- Main Water Source
- Distance to Water Source
- Water Collection Time
- Monthly Health Expenditure
  

# Methodology

The project follows the workflow of an impact evaluation:
1. Defining research question
2. Identifying intervention
3. Defining evaluation methodology
4. Identifying population of target
5. Selection of evaluation sample
6. Collecting Baseline data(Synthetic generation of data)
7. Randomized assignment of treatment
8. Implementation of treatment
9. Follow-up data collection(Synthetic endline data generation)
10. Impact estimation using Microsoft Excel
11. Data Analysis
12. Results and interpretation
